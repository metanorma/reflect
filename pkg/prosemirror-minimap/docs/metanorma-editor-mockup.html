          Semantic Canvas — a WYSIWYM presentation mock-up

          Implements the §5.1–5.5 recommendations for a Metanorma editor (2026 research synthesis), on a generated ~110-page fixture standard: 49 clauses nesting from flat to 7 levels deep, 26 terms, 16 obligation blocks (incl. nested requirement + components/classification/inheritance/profile), symbols dl, sourcecode, a read-only passthrough, footnotes, index marks, 3 figures, 4 tables (a 100-row register map scrolling in-block; a 14-column field table), 3 annexes, bibliography erefs, and two deliberate defects (a broken cross-reference, a “shall” inside a note). AI and collaboration are out of scope. Nothing is print-faithful — meaning is the interface. The editor loads one Semantic XML document per file (<metanorma> root, annexes and clauses internal); .adoc sources are converted first via ⌘K → Import; multi-document works load as collections.
          • Visibility dial (top) — Prose / Annotated / Full structure: one document, three layers of semantic chrome.
          • Node outline (left) — two modes: Clauses (classic) and Blocks — a node-level hierarchy of every block (¶ paragraphs, • list items, terms, requirements, notes, figures/tables/equations). Drag any row to reorder, at any distance, with flavor-model enforcement. Drag a clause's ⋮⋮ handle from the document into the outline for long-distance moves. Alt+Shift+↑/↓ moves the node holding your caret.
          • Reorder with confidence — drag the ⋮⋮ handle on any clause heading (or ▲▼): numbering, outline, minimap and every cross-reference update live; anchors stay stable.
          • Honest defects — a broken cross-reference and a “shall” inside a note: inline squiggle, tree badge, minimap tick and the Problems panel all point at them.
          • Semantic minimap (right) — panning map (reflect-style): for long documents the canvas is taller than the pane (~1:8 floor) and slides as you scroll; the thumb sweeps the pane with the document. Whitespace-gutter nesting, stable landmark spine + detail labels near the viewport, marker lanes: diagnostics · editor notes · search hits · read-wear. Click blocks/labels; drag the thumb; drag the thumb's grip to resize (fit-all ↔ default, double-click resets).
          • Search — ⌘F: highlighting in the document plus a search lane on the minimap; Enter cycles hits.
          • Slash menu — type / in a dashed insertion paragraph; the menu offers only blocks the flavor model allows there.
          • Command palette — ⌘K.
          • Selection toolbar — select text for semantic emphasis.
          • Measure — S/M/L is a pure viewer preference. The editor deliberately offers no print-measure preview: it does not typeset like the PDF toolchain. For print truth, compile via the toolchain.
          • Wide content — the register table scrolls inside its own block; the document never scrolls sideways. Figures open in a lightbox.
          • Margin lane — EDITOR notes live in the margin, never inline. Sticky context header (dismissible, ▾ restores).
          • Themes — light / dark / high contrast, all from design tokens.
